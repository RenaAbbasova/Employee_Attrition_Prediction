# Data

The data file is not stored in this repository.

The dataset is the *IBM HR Analytics Employee Attrition & Performance* dataset, published on Kaggle:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Download `WA_Fn-UseC_-HR-Employee-Attrition.csv` and save it in this folder as `data/HR_Employee_Attrition_Data.csv`.

It has 1,470 rows and 35 columns (age, department, job role, income, overtime, satisfaction scores, years at the company...) and the
column `Attrition`. It is a **fictional** dataset created by IBM data scientists.
